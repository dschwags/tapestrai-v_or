## 🆘 If Deployment Fails

### Check Cloudflare Logs
1. Go to Cloudflare Pages dashboard
2. Select "tapestrai-v3" project
3. View latest deployment
4. Check build logs for errors

### Common Issues
- **Build fails:** Check if all files committed
- **Deploy timeout:** Retry deployment manually
- **404 errors:** Clear cache, wait a few minutes

### Rollback Plan
If v3.3.0 has issues:
1. Go to Cloudflare dashboard
2. Select previous deployment
3. Click "Rollback to this deployment"
4. Site reverts to v3.2.0 instantly
