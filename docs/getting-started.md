# Getting Started with tapestrAI v3.0

Welcome to tapestrAI! This guide will help you get started analyzing your artifacts in minutes.

---

## 📋 What You'll Need

1. **At least one API key** (Gemini is required, others optional)
2. **Clear photos** of your artifact
3. **A modern web browser** (Chrome, Firefox, Safari, Edge)

---

## 🔑 Step 1: Get Your API Keys

### Google Gemini (Required - Free)

1. Visit [Google AI Studio](https://aistudio.google.com/apikey)
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy your key (starts with `AIza...`)

**Cost**: FREE (60 requests/minute)  
**No credit card required**

### OpenAI GPT-4 (Optional - Paid)

1. Visit [OpenAI Platform](https://platform.openai.com/api-keys)
2. Sign in or create account
3. Add payment method
4. Create new API key
5. Copy your key (starts with `sk-...`)

**Cost**: ~$0.01 per analysis  
**$5 free credit for new users**

### Anthropic Claude (Optional - Paid)

1. Visit [Anthropic Console](https://console.anthropic.com/)
2. Sign in or create account  
3. Add payment method
4. Generate API key
5. Copy your key (starts with `sk-ant-...`)

**Cost**: ~$0.003 per analysis  
**$5 free credit for new users**

### Perplexity AI (Optional - Freemium)

1. Visit [Perplexity Settings](https://www.perplexity.ai/settings/api)
2. Sign in or create account
3. Generate API key
4. Copy your key

**Cost**: 5 free requests/day, then paid

---

## 🎯 Step 2: Add Your Keys

1. Open tapestrAI
2. Locate the **API Setup** section
3. For each provider:
   - Click the **eyeball icon** to show/hide your key
   - Paste your API key
   - Click **Test** to verify it works
   - Click **Save** to store it securely

✅ Your keys are encrypted and stored locally on your device

---

## 📸 Step 3: Upload Your Artifact

1. Click the **Upload Area** or drag & drop your photo
2. Supported formats: JPG, PNG, WEBP
3. Max size: 20MB (auto-compressed)
4. For best results:
   - Good lighting
   - Clear focus
   - Show details and markings
   - Include scale reference if possible

---

## 🔬 Step 4: Choose Analysis Depth

The more API keys you add, the deeper the analysis:

- ⭐ **Basic** (1 key) - Material examination
- ⭐⭐ **Enhanced** (2 keys) - + Cultural context
- ⭐⭐⭐ **Comprehensive** (3 keys) - + Historical research
- ⭐⭐⭐⭐ **Professional** (4 keys) - + Expert synthesis

---

## 🚀 Step 5: Start Analysis

1. Click **Analyze**
2. Watch the progress as agents work:
   - 🔬 Material Analyst examines physical features
   - 🌍 Cultural Specialist adds context
   - 📖 Synthesis Curator weaves the story
   - 🔍 Historical Researcher verifies facts
3. Results appear in real-time
4. Review cost breakdown

## 💡 Tips for Best Results

### Photography
- ✅ Natural daylight is best
- ✅ Multiple angles help
- ✅ Show signatures, markings, stamps
- ✅ Include size reference (coin, ruler)
- ❌ Avoid glare and shadows
- ❌ Don't over-filter or edit

### Context
If you know anything about the item, note it:
- Where it came from
- Approximate age
- Previous owner info
- Any markings or labels

### Multiple Images
Upload 2-3 images for better analysis:
- Overall view
- Detail shots
- Back/bottom markings

## ❓ Troubleshooting

### "API Key Invalid"
- Check you copied the full key
- Verify key hasn't expired
- Test directly with provider
- Regenerate key if needed

### "Analysis Failed"
- Check internet connection
- Verify API key is active
- Check provider status pages
- Try again in a few minutes

### "Image Too Large"
- Reduce image size
- Use built-in compression
- Max 20MB per image

### "Rate Limit Exceeded"
- Wait a few minutes
- Check provider limits
- Consider upgrading plan
